🩺 Medi-Appointment (Doctor Appointment Manager)

🔗 Live Site: https://medi-appointment-client.vercel.app

📌 Project Overview

Medi-Appointment is a full-stack doctor appointment management system that allows patients to book appointments, manage schedules, and track appointment status in real time. The platform provides a secure and user-friendly experience for both patients and healthcare providers.

✨ Key Features
Real-time appointment booking and tracking system for patients and doctors.
Secure authentication with Email/Password and Social Login providers.
JWT-based authorization and protected API routes for enhanced security.
Appointment history management with real-time status updates.
Responsive and modern user interface optimized for desktop, tablet, and mobile devices.
Secure user data storage and management using MongoDB.
Role-based access control for different user types.
Fast and seamless user experience powered by modern web technologies.
